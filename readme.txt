DEARDAYS — BEGINNER COLLEGE PROJECT
===================================

FILES
-----
index.html  = page content and sections
style.css   = colours, layout, fonts, responsive design and animations
script.js   = mobile menu, fade-in effects and reminder button

HOW TO OPEN IN VS CODE (WINDOWS)
--------------------------------
1. Extract DearDays.zip to a folder you can find easily, such as Desktop.
2. Open VS Code.
3. Click File > Open Folder...
4. Select the extracted DearDays folder and click Select Folder.
5. In the Explorer panel, click index.html.
6. To preview the website:
   - Recommended: install the "Live Server" extension by Ritwick Dey.
   - Then right-click index.html and choose "Open with Live Server".
   - If you do not want to install an extension, open the folder in File Explorer
     and double-click index.html to open it in your browser.

IMPORTANT
---------
The website uses online Google Fonts and Unsplash photos, so an internet
connection is needed for those resources to load. The HTML, CSS and JavaScript
files themselves are local.

FOR YOUR COLLEGE SUBMISSION
---------------------------
- Replace the sample photos with your own suitable photos if required.
- Personalise the About text and gallery captions.
- Be ready to explain:
  HTML: page structure and content
  CSS: colours, spacing, grid layout, responsive design and hover effects
  JavaScript: mobile navigation, scroll reveal and reminder button

Beginner tip: change one small thing at a time, save with Ctrl+S, then refresh
the browser to see what changed.
